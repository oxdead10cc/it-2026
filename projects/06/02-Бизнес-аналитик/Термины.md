# Словарь терминов приложения

**Система:** веб-приложение, в котором есть учетные записи,
группы, задания, дашборд и календарь.

**Гость:** пользователь, который не зарегистрирован или не выполнил вход. Может только
зарегистрироваться или войти.

**Студент:** зарегистрированный пользователь, выполнивший вход. Про него системе известны
имя, email и пароль. Состоит в любом числе групп и ведет личные задачи.

**Учетная запись:** запись о пользователе в системе: имя, email, пароль.

**Группа:** объединение студентов, которые получают одни и те же задания: учебная группа,
проектная команда, презентационная команда и т. п. Имеет название и ссылку приглашения.
Студент может состоять в нескольких группах.

**Участник группы:** студент, состоящий в группе. В каждой группе у участника есть роль:
"админ" или "участник".

**Админ группы:** участник с правом управлять группой: публиковать, изменять и удалять
общие задания, перевыпускать ссылку приглашения, назначать админов, исключать участников,
удалять группу. Создатель группы становится админом автоматически. В группе может быть
несколько админов.

**Ссылка приглашения:** короткая ссылка, по которой студент вступает в группу. Админ может
перевыпустить ссылку, после этого старая ссылка перестает работать.

**Задание:** то, что нужно сделать к сроку. Бывает двух видов: общее задание и личная задача.

**Общее задание:** задание, опубликованное админом в группе. Видно всем участникам группы.
Содержит название, описание (необязательно) и срок сдачи.

**Личная задача:** задание, которое студент создал для себя. Видна только автору. Содержит
название, описание (необязательно) и срок сдачи.

**Срок сдачи:** дата и время, к которым задание нужно выполнить.

**Статус задания:** отметка студента о ходе работы: "не начато", "в работе" или "готово".
Каждый студент ведет статус по каждому заданию сам, и этот статус видит только он.

**Срочное задание:** невыполненное задание, до срока сдачи которого осталось не больше 3 суток.

**Просроченное задание:** задание, срок сдачи которого прошел, а статус не "готово".

**Дашборд:** главная страница вошедшего студента. Показывает невыполненные задания из всех
его групп и его личные задачи, отсортированные по сроку; срочные и просроченные подсвечены.

**Календарь:** раздел, где задания разложены по датам сроков. Есть вид "неделя" и "месяц".

**Раздел "Профиль":** страница с данными учетной записи студента: имя, email, смена пароля.
