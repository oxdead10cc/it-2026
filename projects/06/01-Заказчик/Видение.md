# Видение проекта

## Тема проекта

Веб-приложение для контроля заданий и сроков сдачи заданий для студентов.

## Описание

В приложении работают студенты. Студент может создать группу и состоять в нескольких группах. Студент, который создал группу, становится ее администратором и может приглашать туда других студентов по ссылке приглашению. Администратор может создать новое задание и указать ему срок сдачи. Так, например, староста может внести домашнее задание, которое задали всей группе. Студенты могут менять статус для каждого задания, помещать, что задание в работе или выполнено. Для каждого студента отображаются задания всех групп, в которых он состоит, а также студент может создавать личные задания. Доступен календарный вид и overview на главной странице.

## Цели

- Не пропускать сроки сдачи заданий
  - видеть срочные и просроченные задания на главной странице
- Собрать все нужные задания в одном месте для всех групп студента (Полезно, если студент становится вольнослушателем или у него есть проектная группа или что-нибудь такого рода)
  - не искать задания по чатам разных групп

## Задачи

- Реализовать регистрацию и вход в приложение
- Реализовать группы: создание, приглашение по коду, роли "админ" и "участник"
- Реализовать публикацию общих заданий админом группы
- Реализовать ведение личных задач
- Реализовать личный статус выполнения задания
- Реализовать дашборд с подсветкой срочных и просроченных заданий
- Реализовать календарь заданий

## Вне рамок проекта

- Уведомления вне приложения (email, Telegram, push)
- Сдача и проверка работ, роль преподавателя
- Просмотр админом прогресса участников группы
- Комментарии и обсуждения под заданиями
- Вложения к заданиям
